# 实验图表约定

核心论点：展示通信版本差异及候选Store复制的独立开销，展示本地前缀截取在预算、事实保留、重复计算和持久存储之间的取舍，不预设整体加速或业务质量提升。

图型采用定量网格。通信图完整覆盖36个配置和三个版本，分别展示延迟与分配量；吞吐量、写入量和检查点大小进入完整数据表。压缩图覆盖12个配置和三种模式，展示保留计数量、事实标记保留率、重复读取延迟和摘要计算次数；首次读取、重新打开仓库和存储开销另有完整表。

绘图后端沿用已保存的Python选择，使用matplotlib；不使用生成式图像制作数据图。导出双栏宽183mm、可编辑文字的SVG/PDF和600dpi的PNG/TIFF；压缩图与通信图分别排版。每个点为六轮试验估计值的中位数，误差线为完整最小值至最大值；重复读取先在同一轮内取均值，不当作独立试验。没有显著性检验，不画星号。

预热数据和方法预检完整保留但不参与正式汇总。正式运行不删除慢样本；如某次完整运行有已知外部干扰，则整次保留并说明不用于主结论的原因，而不是挑选其中较快轮次。图表必须从独立核验通过的原始结果生成，附原始数据、汇总表、脚本及图注。原版隔离缺陷和本地计量边界必须在图注中说明。
